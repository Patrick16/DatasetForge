Runs fully locally via ONNX Runtime -- no Ollama/LM Studio/cloud API needed. First use downloads the model from Hugging Face (roughly 50–800MB depending on the preset) and caches it; every run after that is fast (confirmed live: ~0.2s per image on CPU for the default preset once loaded).

Caption an existing folder

Captions every image already in a folder, independent of any download above — uses the Method and Settings configured above (Vision LLM or WD14 Tagger).

A trigger word is a token every caption should consistently include — common for LoRA/Dreambooth training sets. With the Vision LLM method, what it stands for changes how it should read in a sentence, so tell us its role below. With WD14 Tagger, it's simply prepended as the first tag regardless of role (a flat tag list doesn't have sentence grammar to fit a role into).

Remove duplicate images

Scans a folder for images with byte-identical content (exact hash match, same rule used to skip duplicates during a download) and removes every copy but one. Removed files go to the Recycle Bin, not a permanent delete -- and any orphaned .txt caption for a removed duplicate goes with it.
